# 🎆 불꽃놀이 디스플레이 (Fireworks Display)

이 프로젝트는 React와 TypeScript, 그리고 Vite를 사용하여 만든 화려한 불꽃놀이 효과를 보여주는 웹 사이트입니다. 새해를 축하하거나 특별한 메시지를 전달하기 위해 제작되었습니다.

## 🚀 주요 기능

- **자동 불꽃 생성**: 일정 시간마다 화면 곳곳에서 다양한 색상의 불꽃이 자동으로 터집니다.
- **클릭 이벤트**: 화면을 클릭하면 클릭한 위치에서 즉시 새로운 불꽃이 생성됩니다.
- **부드러운 애니메이션**: HTML5 Canvas를 활용하여 수많은 파티클이 중력의 영향을 받아 떨어지는 부드러운 애니메이션을 제공합니다.
- **반응형 디자인**: 창 크기를 조절해도 배경과 애니메이션이 화면에 맞게 자동으로 조정됩니다.
- **축하 메시지**: "HAPPY NEW YEAR"와 같은 감동적인 메시지를 표시합니다.

## 🛠 기술 스택

- **Frontend**: React 19, TypeScript
- **Build Tool**: Vite (Rolldown 기반)
- **Styling**: Tailwind CSS (사용 가능 환경)
- **Rendering**: HTML5 Canvas API

## 💻 실행 방법

### 사전 준비
- Node.js 설치가 필요합니다.

### 설치 및 실행
1. 저장소를 클론하거나 다운로드합니다.
2. 터미널에서 아래 명령어를 입력하여 의존성을 설치합니다.
   ```bash
   npm install
   ```
3. 아래 명령어로 개발 서버를 실행합니다.
   ```bash
   npm run dev
   ```
4. 브라우저에서 표시되는 로컬 호스트 주소(기본값: `http://localhost:5173`)로 접속합니다.
